# The Snake (Изгиб Питона)

Классическая игра «Змейка» на Python с использованием библиотеки Pygame.

## О проекте
Игрок управляет змейкой, которая ест яблоки и растет. При столкновении с собой игра сбрасывается. Скорость увеличивается с каждым съеденным яблоком. Реализованы звуковые эффекты и телепортация через стены.

## Управление
Стрелки на клавиатуре (Вверх, Вниз, Влево, Вправо).
